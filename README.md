# Spring Pet Clinic App 🐾

A simple web application for managing pet clinic data, built with Spring Boot as part of a hands-on Java development course.

## 🚀 Features
- Full CRUD functionality for Owners, Pets, and Veterinarians
- Clean MVC architecture using Spring Boot
- Service and Repository layers using Spring Data JPA
- Dynamic HTML views rendered with Thymeleaf
- In-memory H2 database
- Multi-module project using Maven

## 🧰 Tech Stack
- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- Maven
- H2 Database

## 🔧 How to Run Locally

```bash
git clone https://github.com/MJCarvajalQ/sfg-pet-clinic.git
cd sfg-pet-clinic
./mvnw spring-boot:run
Once the app is running, open your browser and go to:
http://localhost:8080/
